# Grazioso Salvare Animal Shelter Dashboard

**CS-499 Computer Science Capstone**  
**Artifact Category:** Algorithms and Data Structures

The Grazioso Salvare Animal Shelter Dashboard is a Python application originally developed in CS-340 Client/Server Development. The application uses animal shelter data to display rescue candidates through an interactive Dash dashboard with filtering, tables, and location information.

For my CS-499 capstone, I returned to the original application and expanded it from basic filtering into a more complete data processing and ranking system.

## Capstone Enhancement

The enhanced version focuses on improving how animal intake and outcome data is prepared, matched, scored, and presented to the user.

Major improvements include:

- Data preparation and validation for intake and outcome records
- Temporal matching of intake and outcome records using animal IDs and dates
- Rescue suitability scoring based on breed, age, and sex
- Ranking of animals based on rescue mission requirements
- Refactored dashboard integration using prepared and scored data
- Improved location handling and map fallback behavior
- More modular code that is easier to test and maintain
